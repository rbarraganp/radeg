-¿QUÉ ES RADEG?:

RADEG es una aplicación web para realizar el Registro de Actividades Durante Entrenamiento En Gimnasio,
útil para aquellos deportistas que quieran llevar un registro de sus progresos. Los usuarios podrán tener la 
opción de registrar todas las actividades que realizan, personalizar los detalles del ejercicio, añadir y modificar
los grupos musculares y subgrupos musculares al que pertenece cada actividad, peso utilizado, tiempo de descanso, número
de repeticiones y duración. Con todo esto podremos tener a nuestra disposición toda la información de nuestros progresos.
